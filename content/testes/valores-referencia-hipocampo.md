VALORES DE REFERÊNCIA — CONTROLES: HIPOCAMPO
Nenhum dos ensaios abaixo tem, no material de referência consultado para este manual, uma faixa de controle estabelecida especificamente para hipocampo — o hipocampo usa o mesmo protocolo laboratorial do córtex cerebral (ver seções de cada ensaio), mas baseline de enzimas e metabólitos costuma variar entre regiões encefálicas, então as faixas do córtex abaixo servem só como ponto de partida provisório, não como valor validado para hipocampo. Até que o laboratório estabeleça sua própria faixa de referência com seus grupos controle de hipocampo, use estas faixas com cautela.
